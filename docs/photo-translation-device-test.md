# 사진 번역 실기기 확인 목록

계획 `docs/superpowers/plans/2026-11-26-photo-translation.md` Task 15의 실기기 확인을 서버가 필요한 것과 필요하지 않은 것으로 나눈다.

**지금 정한 범위(2026-11-26 사용자 결정)**
- Claude·Google을 포함한 유료 외부 API는 호출하지 않는다.
- 실제 번역 품질과 외부 API 연동은 확인하지 않는다(미검증).
- 결과 화면은 개발용 가짜 번역으로 확인한다.

## 1. 서버 없이 확인(개발용 가짜 번역)

```bash
flutter run --dart-define=TRIPBLER_PHOTO_FAKE_TRANSLATION=true
```

- 디버그·프로필 빌드에서만 켜진다. 릴리스 빌드에서는 이 값을 넣어도 꺼진다(`lib/services/fake_photo_translation.dart`의 `photoFakeTranslationEnabled`).
- 켜지면 번역 탭이 사진 번역 화면이 된다. 사진과 글자를 어디에도 보내지 않고, 로그인도 쓰지 않는다.
- 앱 로그인은 필요 없다. 저장된 세션이 없으면 `AuthGate`가 로그인하지 않은 상태로 메인 화면을 연다.
- 저장된 세션이 있는데 서버가 없으면 위쪽에 세션 복구 실패 배너가 보일 수 있다. 사진 번역 확인에는 영향이 없다.
- 동의 대화상자는 실제 전송 문구 그대로 나온다. 동의 흐름을 서버 없이 확인하려고 그대로 두었다.
- 기기에서 실제로 읽은 OCR 문단 ID마다 가짜 번역을 붙인다.
- 화면에는 가짜임을 알리는 띠가 보인다.
  - 촬영 화면: "개발용 가짜 번역 · 사진과 글자를 보내지 않아요"
  - 결과 화면: "가짜 번역 결과 · 실제 번역이 아니에요 (개발용)"
  - 상세 시트: 같은 취지의 띠
- 모든 번역은 `[가짜]`로 시작한다.
- 가짜 결과는 화면 확인을 위해 문단 순서에 따라 모양이 바뀐다.
  - 첫째: 짧은 번역
  - 둘째: 상자보다 긴 번역
  - 셋째: 원문 글자 수를 적은 번역
  - 넷째: `[읽을 수 없음]`이 들어간 불확실 번역
  - 다섯째 문단마다: 대체 번역 표시
  - 원문에 숫자가 있는 문단: 가짜 가격(짝수 번째는 확정·원화 환산, 홀수 번째는 미확정)
- 가짜 원화 환율(9.5)은 실제 값이 아니다.

| 확인 항목 | 기대 |
| --- | --- |
| 촬영·갤러리 사진(세로, 가로, EXIF 회전, 갤러리) | 결과 상자가 원문 글자 위에 놓인다 |
| 확대·이동 | 상자가 사진과 함께 움직이고 어긋나지 않는다 |
| 상자 누르기 | 상세 시트에 원문·가짜 번역·가짜 발음·가격·불확실/대체 이유가 보인다 |
| 원문 보기 토글, 재촬영 | 상자가 숨겨졌다 다시 보이고, 재촬영하면 촬영 화면으로 돌아간다 |
| 긴 번역, 작은 상자 | 줄바꿈·말줄임이 되고 아래 상자를 가리지 않는다 |
| 늦은 결과 | 가짜 번역 대기(0.7초) 중 재촬영하면 이전 결과가 나타나지 않는다 |
| 동의 대화상자 | 처음에 묻고, 취소하면 촬영 화면으로 돌아가며, 동의하면 다음부터 묻지 않는다. 가짜 모드에서도 대화상자 흐름은 같다(실제로 보내지는 않음) |
| 동의 버전 | `PhotoConsentStore.currentVersion`을 올린 빌드에서 다시 묻는다 |
| 동의 백업·복원(Android) | `adb shell bmgr backupnow <패키지>` → 삭제 → 재설치 → 복원 뒤 다시 묻는다 |
| 임시 파일 | 촬영·취소·재촬영·완료 뒤 앱 임시 폴더에 `photo_*.jpg`가 남지 않는다(디버그 빌드) |
| ML Kit 줄 상자 | 정리된 기준 사진 좌표와 맞는다(단위 테스트로 확인하지 못한 부분) |
| 탭 이동 | 번역 탭을 떠나면 카메라가 멈추고, 돌아오면 다시 켜진다 |

## 2. 로컬 서버가 필요한 확인

실제 업로드는 `--dart-define=TRIPBLER_PHOTO_TRANSLATION=true --dart-define=TRIPBLER_API_BASE_URL=http://<PC LAN IP>:8080`(가짜 번역 끔)으로 한다. PostgreSQL, 로그인 계정, 서버 환경 변수가 필요하다.

**보류: 성공 업로드**
- 지금 서버는 형식이 올바른 사진 요청을 받으면 번역을 외부 제공자에게 맡긴다.
  - Claude 키가 있으면 Claude를 호출한다.
  - Claude 키가 없으면 모든 문단을 Google 대체 번역으로 보낸다.
- 따라서 앱에서 보낸 정상 업로드는 외부 호출로 이어진다. 유료 호출을 허용하기 전까지 보류한다.
- 서버는 `GOOGLE_TRANSLATION_APIKEY` 값이 있어야 시작한다(기본값 없음). 정상 업로드를 하지 않으면 이 키로 외부 호출이 나가지 않는다.

**외부 호출 없이 할 수 있는 것**: 아래 항목은 번역 단계 전에 끝난다. 정상 요청이 섞이지 않게 주의한다.

| 확인 항목 | 기대 |
| --- | --- |
| 로그인하지 않았거나 토큰이 만료된 상태에서 업로드 | 401, 앱이 로그인 만료 안내를 보인다. 서버는 본문을 해석하지 않는다 |
| 서버가 꺼져 있거나 주소가 틀림 | 연결 실패 안내와 다시 시도 버튼 |

**외부 호출을 허용한 뒤**
- 성공 업로드와 결과 표시
- 서버 임시 파일과 로그 비저장
- 호출 한도 429와 동시 처리 거절 안내
- 문단별 대체 표시

이 항목들은 실제 번역 품질 측정(Task 14)과 함께 진행한다.
