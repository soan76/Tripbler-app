# 암호화폐 통화 행 연결

- `lib/crypto`: Tripbler 암호화폐 API, 코인/현재가 모델, 목록·선택·현재가 상태.
- `lib/presentation/exchange`: 공통 `DisplayCurrency`와 두 도메인을 화면에 연결하는 `ExchangeDisplayProvider`.
- 기존 ExchangeProvider와 환율 API에는 암호화폐 심볼을 전달하지 않는다.
- 통화 관리와 메인은 공통 모델을 사용한다. 메인의 CurrencyRow/AmountInputField를 재사용한다.
- 통화 행의 통화명(▾)이나 “통화 추가 / 편집”을 터치로 누를 때 초점이 금액 입력칸에 있으면 먼저 푼다. 창을 닫거나 통화를 고른 뒤 입력칸으로 돌아가 키보드가 뜨거나 화면이 움직이는 일을 막는다. 입력값과 환산값은 입력할 때마다 반영되므로 그대로 남고, 입력칸을 다시 누르면 키보드가 뜬다. 키보드로 열면 초점이 누른 버튼에 있으므로 닫을 때 그 버튼으로 돌아온다. 설정 화면에는 입력칸이 없어 이 처리가 없다.

## 서버 계약

`GET /api/v1/crypto/coins`의 `symbol`, `name`으로 지원 목록을 구성한다. 7개 코인은 Flutter 제품 코드에 하드코딩하지 않는다.
`GET /api/v1/crypto/price?coin=BTC&currency=KRW`의 `symbol`, `currency`, `price`, `fetchedAt`을 사용한다.
외부 API ID/키는 Flutter에 저장하지 않는다. 기존 `TRIPBLER_API_BASE_URL` 설정을 공유한다.

## 표시와 저장

메인의 큰 숫자는 해당 코인의 환산 수량이다. 보조 문구는 1코인의 KRW 가격과 조회 시각(기기 현지 시각)이다.
기준 금액 × 기준 통화→KRW 환율 ÷ 코인 KRW 가격으로 계산하며, 코인 수량을 입력하면 역산한다.
KRW가 기준이면 연결 환율은 1이며, 다른 기준 통화일 때만 표시 계층에서 기존 법정 통화 API로 KRW 환율을 요청한다.
코인을 메인의 기준 통화로 선택하는 기능은 포함하지 않는다.

선택 코인과 마지막 성공 목록은 `crypto.selected.v1`, `crypto.catalog.v1`에 저장한다.
혼합 행 순서는 `exchange.displayOrder.v1`에 `fiat:USD`, `crypto:BTC` 형식으로 저장한다.
편집 창에서 완료를 눌러야 추가/삭제/순서가 적용되며, 창을 닫으면 초안을 버린다.
최초 목록 조회에는 서버 연결이 필요하다. 이후 서버 연결 실패 시 저장된 목록으로 편집할 수 있다. 현재가 갱신에 실패하면 마지막 성공값과 조회 시각을 유지하고 저장값임을 표시한다. 성공값도 없으면 `—`로 표시하고 입력을 막는다.
아래로 당겨 새로고침하면 환율과 암호화폐 현재가를 다시 조회한다. 오류가 없는 이전 현재가를 재조회 중 표시할 때는 기존 조회 시각을 유지한다.

## 공통 차트와 Crypto History

- 차트 통화쌍은 위쪽 환율 계산용 통화 선택과 따로 관리한다(`ChartSelectionProvider`). 어느 쪽을 바꿔도 다른 쪽에는 영향을 주지 않는다. 통화/암호 전환 버튼은 없고, 국가 통화 쌍과 코인 쌍이 한 캐러셀(`ChartPairCarousel`)에 섞인다.
- 카드는 1~5개이며 기본값은 `USD/KRW`, `JPY/KRW`, `BTC/KRW`다. 마지막 페이지의 “차트 추가”로 아직 없는 `통화/KRW` 쌍을 더하고, 카드의 더보기(⋮)를 눌러 삭제 모드를 연 뒤 “차트 삭제”로 지운다(마지막 한 장은 남긴다). 삭제 모드에서는 카드 내용을 반투명 층으로 가볍게 흐리고 가운데에 버튼을 보여 주며, 차트 터치와 툴팁은 꺼진다. 초점은 버튼으로 옮겨 가고, 카드의 버튼 밖을 누르거나 뒤로 가기·Esc로 닫으면 더보기로 돌아온다. 다른 페이지나 탭으로 넘어가도 닫힌다. 세로 스크롤로 삭제 버튼의 가운데가 스크롤 영역 밖으로 나가도 초점을 돌려주지 않고 닫아, 보이지 않는 모드가 뒤로 가기를 먹거나 Enter로 카드를 지우지 않는다. 세로로 조금 끄는 것은 모드를 유지한다. 더보기만 보이는 자리에서 열어 버튼이 처음부터 가려져 있으면, 버튼이 한 번 보였다가 다시 가려지거나 카드 전체가 나갈 때 닫는다. 키보드가 열리거나 닫히는 중이거나 위에 다른 화면이 있을 때는 재지 않는다. 초점이 층 밖으로 나가면(서랍, 입력창, Tab 이동) 초점을 돌려주지 않고 닫는다. 바텀시트나 다른 화면이 위에 올라오거나 앱 전환으로 초점이 잠시 사라질 때는 닫지 않으며, 돌아오면 초점도 버튼으로 돌아온다. 현재 페이지가 아닌 카드는 초점을 받지 않아 키보드로 조작할 수 없다. 전에 쓴 금액 입력칸으로 초점이 되돌아가 키보드가 뜨고 화면이 올라가지 않도록, 모드를 열 때 초점 기록을 비우고, 초점이 캐러셀 페이지 안에 있는 채 페이지를 넘기거나 기간이나 카드 목록이 바뀌면 초점을 풀어 화면 전체로 보낸다. 입력칸에 초점이 있으면 건드리지 않아 키보드를 띄운 채로 넘길 수 있다. 같은 통화쌍은 두 카드에 둘 수 없으며, 방향만 다른 쌍(`USD/KRW`와 `KRW/USD`)도 뒤집으면 같은 차트이므로 같은 쌍으로 본다. 선택창에서 다른 카드에 이미 있는 차트를 고르면 두 카드의 위치를 서로 바꾼다. 페이지는 그대로라 지금 자리에서 고른 차트가 보이고, 두 카드는 받아 둔 데이터를 유지한다. 옮겨 온 카드는 고른 통화가 누른 쪽에 보이는 방향으로 표시하고(`ChartSelectionProvider.swappedAfterExchange`, 카드 ID로 `chart.swapped.v1`에 저장), 스왑을 누른 것이 아니라 다른 차트로 바뀌어 보이는 것이므로 이동 애니메이션과 그래프 페이드 없이 바로 보여 준다. 다른 자리로 밀려난 카드는 자기 방향을 유지한다. 순서대로 `chart.pairs.v1`에 `fiat:USD/KRW`, `crypto:BTC/KRW` 형식으로 저장하며, 처음 상태는 저장하지 않는다. 저장값을 읽을 때도 같은 기준으로 중복을 거르고, 읽기 전의 추가·변경·삭제는 무시한다.
- 카드 위쪽의 두 통화명(▾)을 누르면 검색 선택창이 열린다. 통화 관리의 “표시되지 않은 통화”와 같은 검색 입력·통화/암호 전환·목록 줄(`currency_search_parts.dart`)을 쓴다. 두 통화가 같아지는 통화는 후보에서 뺀다. 코인을 고르면 어느 쪽이든 `코인/KRW`가 되고, 코인 쌍의 KRW 쪽에는 KRW만 보인다(서버 Crypto History가 KRW만 제공). 통화를 바꿔도 화면의 좌우는 유지한다. 누른 쪽에 고른 통화가, 반대쪽 통화도 원래 자리에 남는다(뒤집힌 “KRW ⇄ USD”의 KRW를 EUR로 바꾸면 “EUR ⇄ USD”). 코인을 고르면 고른 쪽에 코인이 보이게 방향을 정한다(오른쪽에서 고르면 “KRW ⇄ 코인”). 고른 차트가 다른 카드에 있어 위치를 바꾸는 경우도 같다(“USD ⇄ KRW”의 KRW를 JPY로 고르면 있던 카드가 `JPY/USD`여도 “USD ⇄ JPY”). 선택창이 열린 사이 카드가 지워지거나 바뀌었으면 고른 통화를 반영하지 않는다. 터치로 열 때 초점이 금액 입력칸에 있으면 먼저 풀어, 창을 닫아도 입력칸으로 돌아가 키보드가 뜨거나 화면이 올라가지 않는다. 입력값은 입력할 때마다 반영되므로 그대로 남는다. 키보드로 열면 초점이 통화 버튼에 있으므로 취소하면 그 버튼으로 돌아오고, 통화나 위치를 바꾸면 카드가 바뀌어 초점이 화면 전체로 간다. 창 안의 검색 입력칸은 창과 함께 사라져 키보드도 내려간다.
- 받은 코인 목록(`crypto.catalog.v1` 저장값 포함)에 없는 코인 카드는 조회하지 않고 “지원하지 않는 코인입니다. / 통화명을 눌러 다른 코인을 골라 주세요.”를 표시한다. 코인 목록을 아직 못 받았거나 조회에 실패해 비어 있으면 지원 여부를 판단하지 않고 조회한다. 저장된 카드는 지우지 않는다.
- 모든 카드가 `MarketChartCarousel`, `MarketChartCard`, 기존 `ExchangeRateLineChart`와 축/툴팁/터치 로직을 공유한다.
- `ChartPoint`는 공통 렌더링 계약이며 기존 환율 모델은 3자리 통화 코드 검증을 유지한다. Crypto History는 별도 모델로 파싱한 뒤 표시 계층에서 `ChartSample`로 변환한다.
- 조회는 `ExchangeChartDataSource`와 `CryptoChartDataSource`로 분리한다. 암호화폐는 `/api/v1/crypto/history?coin=BTC&currency=KRW&period=1M`과 현재가 API만 사용한다.
- 카드의 통화 바꾸기 버튼은 다시 조회하지 않고 받은 값을 1/rate로 뒤집어 표시한다. 스냅샷은 원래 방향으로 저장한다. 뒤집은 카드 ID는 `chart.swapped.v1`에 `fiat:KRW/USD`, `crypto:BTC/KRW` 형식으로 저장한다. 선택창에서 카드의 통화를 바꾸면 화면의 좌우가 유지되는 방향(`ChartSelectionProvider.swappedAfterReplace`)을 새 카드 ID에 저장한다. 이 값은 한 번 쓰면 비우며, 선택창을 거치지 않고 같은 자리 카드가 바뀌면(알려 준 방향이 없으면) 옛 방향을 옮기지 않고 새 카드를 정방향으로 둔다. 국가 통화와 코인 카드가 한 캐러셀에 섞이므로, 현재 카드에 없는 ID(지운 카드, 바꾸기 전 통화쌍, 앱 업데이트 전의 옛 저장값)는 종류(`fiat:`/`crypto:`)와 상관없이 저장값을 읽은 뒤 지운다. 현재 목록이 비어 있으면(목록을 아직 못 받은 상태일 수 있음) 지우지 않는다.
- 기간 버튼은 7D/1M/3M/6M/1Y/2Y/5Y 모두 유지한다. 암호화폐의 2Y/5Y는 불필요한 API 호출 없이 “암호화폐 차트를 불러오지 못했습니다.”를 표시한다.
- 보이는 카드만 최초 조회한다. 기간 변경, 카드의 통화 변경이나 제거 이후의 늦은 응답은 반영하지 않는다.
- Crypto 시각은 epoch 밀리초에서 UTC로 파싱하고 기기의 현지 시각으로 표시한다. 툴팁은 시·분도 보여준다. 서버는 History를 기본 최대 300점으로 축소하며 각 구간의 최저/최고점 및 첫/마지막 점을 보존한다.

## 느린 네트워크 처리

- 초기화는 로컬 복원 완료 후 반환한다. 저장된 목록과 가격을 먼저 표시하고, 네트워크 갱신은 백그라운드에서 진행한다.
- 코인 목록과 선택 코인 가격은 병렬 조회한다. 차트의 현재가와 History도 병렬 조회하며 현재가만 실패하면 History는 표시하고 금액을 `최근 기록`으로 명시한다.
- 법정 통화 환율은 기존 저장소, 코인 현재가와 차트는 `MarketSnapshotStore`에 마지막 성공 응답을 저장한다. 후자는 최대 64개 항목이며 저장 실패가 화면의 성공 응답을 없애지 않는다.
- 앱 시작 시 복원 허용 나이: 법정 환율/KRW 연결 환율 3일, 코인 현재가 15분, 법정 History 7일, Crypto History 1일. `fetchedAt`으로 판단하며 재저장 시 시간을 갱신하지 않는다.
- 갱신 중에도 차트와 가격을 유지한다. 실패하면 마지막 성공 데이터 표시를 안내하며, 성공 시 최신 값으로 교체한다. 기준 통화/코인/기간별 캐시를 분리한다.
- 서버 타임아웃 fallback은 `stale: true`와 기존 `fetchedAt`을 반환한다. 프론트는 이를 저장값/갱신 지연 상태로 표시한다.
- 서버 JSON 압축은 `Accept-Encoding: gzip`을 지원하는 클라이언트에 1KB 이상 응답부터 적용된다.
