# 번역 탭 흰 상자 결과: 기기 읽기 + 글자 번역 (짧은 설계)

작성: 2026-11-27 · 상태: 설계안(사용자 승인 전) · 바탕: `2026-11-26-photo-translation-design.md`

## 왜

기본 번역 탭은 찍은 뒤 줄 목록을 보여 준다. 기획은 찍은 사진의 원문 자리에 흰 상자로 번역을 보여 주는 것이다. 사진 AI 번역(나중에 Gemini)은 유료 호출을 보류했으므로, 그 전까지 **사진은 보내지 않고** 지금 쓰는 번역으로 흰 상자 화면을 쓰게 한다(사용자 결정 2026-11-27, "2번으로 하고 나중에 Gemini로 사진 번역을 바꾸자").

## 무엇을 바꾸나

1. **번역 탭은 늘 사진 번역 화면(`PhotoTranslationScreen`)을 쓴다.** 촬영 화면(목업), 흰 상자 결과, 확대·이동, 원문 보기, 상세 시트는 이미 있는 것을 쓴다.
2. **번역 방식을 고를 수 있게 한다**(`PhotoTranslationNotifier._upload` 자리).

| 방식 | 언제 | 사진 전송 | 동의 대화상자 | 번역 |
| --- | --- | --- | --- | --- |
| 기기 읽기 + 글자 번역 (새 기본) | 아무 설정 없이 실행 | 안 함 | 묻지 않음 | 기기 OCR 문단의 글자만 서버 번역 API로 |
| 사진 AI 번역 | `--dart-define=TRIPBLER_PHOTO_TRANSLATION=true` (나중에 Gemini로 바꾼 뒤 기본으로) | 함 | 지금처럼 묻는다 | 서버 사진 번역 API |
| 개발용 가짜 | `TRIPBLER_PHOTO_FAKE_TRANSLATION=true` (릴리스 제외) | 안 함 | 지금처럼 | 가짜 결과 |

3. **기기 읽기 + 글자 번역의 번역 호출**(기본 화면이 지금 쓰는 두 API를 그대로 쓴다. 새 유료 API는 없다)
   - 로그인했으면 줄별 번역 API(`POST /api/v1/translation/lines`)에 문단마다 한 줄로 보낸다. 번역·한글 발음·가격(원화 환산)이 온다.
   - 로그인하지 않았으면 기존 통번역 API로 문단마다 번역한다(동시에 최대 4개). 발음·가격은 없다.
   - 줄별 API 제한(50줄, 줄 200자, 합계 5000자)을 넘는 문단은 보내지 않고 "일부만 번역했어요"로 알린다.
   - 결과는 문단 ID로 흰 상자에 붙인다. 새 출처 값 `PhotoTranslationSource.deviceText`를 두어 상자에 "대체 번역" 표시가 붙지 않게 한다.
4. **촬영 화면 안내**: 처음에는 기기에서 읽는다는 작은 안내를 두었으나, 2026-11-27 사용자 요청으로 촬영 화면의 안내 문구(촬영 안내·기기/전송 안내·메뉴 꼬리표)를 모두 없앴다. 사진 AI 번역의 사진 전송은 처음 촬영 때 동의 대화상자로 알린다.

## 그대로 두는 것

- 하단 메뉴, 촬영 화면 배치, 흰 상자 결과 화면 모양.
- 서버(`backend/`)는 바꾸지 않는다.
- 사진 AI 번역 경로와 동의 흐름(나중에 Gemini로 바꿀 때 쓴다).

## 나중에(이번 범위 밖)

- 기존 번역 화면(`TranslationScreen`, 줄 목록 결과)은 번역 탭에서 빠진다. 실기기 확인 뒤 코드와 테스트를 지운다.
- Gemini 연결 뒤 기본 방식을 사진 AI 번역으로 바꾼다.

## 한계

- AI가 사진을 보고 원문을 고치는 보정은 없다. 기기 OCR이 읽은 대로 번역한다.
- 로그인하지 않으면 발음·가격이 없다(지금 기본 화면과 같다).
- 문단을 한 줄로 보내므로 줄바꿈이 많은 문단은 번역이 한 덩어리로 나온다.
