01 환율

아무 줄에나 금액을 넣으면
나머지가 따라 바뀝니다

여행지에서는 "이 가격이 우리 돈으로 얼마지?"를 하루에도 수십 번 묻게 됩니다. 기준 통화를 따로 고르지 않고, 지금 보고 있는 가격표의 통화 줄을 눌러 그대로 입력하면 됩니다. 입력 중인 줄은 파란 배경으로 표시됩니다.

  • 국가 통화와 코인법정 통화와 암호화폐를 한 목록에서 환산합니다. 코인 줄에는 현재가와 조회 시각을 함께 보여 줍니다.
  • 오프라인에서도마지막으로 받은 값을 먼저 띄우고 뒤에서 다시 조회합니다. 갱신에 실패하면 "저장값"으로 표시해 오래된 값임을 알립니다.
  • 통화 추가 / 편집지원 코인 목록은 서버에서 받아 오므로 앱을 업데이트하지 않아도 늘어납니다. 순서와 표시 여부는 기기에 저장됩니다.
  • 자릿수 제한설정에서 소수점 자릿수를 자동 또는 고정 값으로 정할 수 있습니다.
02 환율 흐름

위쪽 환산 목록과 별개로 보고 싶은 통화쌍을 차트 카드로 모아 둡니다. 카드를 옆으로 넘기며 여러 쌍을 비교하고, 화살표 버튼으로 기준을 뒤집을 수 있습니다.

  • 7일부터 5년까지7D · 1M · 3M · 6M · 1Y · 2Y · 5Y 일곱 구간을 지원합니다.
  • 짚어 보는 차트그래프를 누른 채 움직이면 그날의 환율과 오늘과의 차이를 보여 주고, 손을 뗀 뒤에도 3초간 유지해 값을 읽을 시간을 줍니다.
  • 금액 환산차트 아래 입력칸에서 선택한 날짜의 환율로 바로 계산해 볼 수 있습니다.
  • 코인 차트코인은 원화 기준 시세 차트를 같은 카드 형식으로 보여 줍니다.

03 지도

찾고, 보고,
바로 길을 엽니다

장소 이름을 검색하면 결과를 지도 아래 목록으로 보여 주고, 하나를 고르면 평점과 영업 여부가 담긴 카드가 올라옵니다. 길찾기는 Google 지도로 넘겨 줍니다.

  • 현지 언어로 검색장소 검색은 서버를 거쳐 Google Places로 요청합니다. 앱에는 외부 API 키가 없습니다.

  • 호출 제한서버가 사용자별·전체 호출 수를 제한해 비용이 갑자기 늘지 않게 막습니다.

04 번역

메뉴판을 찍으면
원문과 번역을 나란히

카메라로 간판이나 메뉴판을 찍거나 갤러리에서 사진을 고르면, 글자를 인식해 번역합니다. 결과는 카드 두 장으로 나뉘어 좌우로 밀며 원문과 비교할 수 있습니다. 지금은 글자 인식까지 동작하고, 서버를 거치는 번역 연결은 진행 중입니다.

  • 글자 인식은 기기에서ML Kit로 휴대폰 안에서 글자를 읽고, 사진은 서버로 보내지 않습니다. 인식된 텍스트만 번역에 씁니다.
  • 언어 바꾸기원문과 번역 언어를 고르고, 가운데 버튼으로 서로 바꿀 수 있습니다.
  • 권한 안내카메라 권한이 없거나 차단된 경우를 나눠, 다시 요청할지 기기 설정으로 보낼지 안내합니다.
  • 어두운 곳에서플래시를 켜고 끌 수 있고, 지원하지 않는 기기에서는 이유를 알려 줍니다.

05 탭 메뉴

화면을 가리지 않는
부채꼴 메뉴

지도와 카메라는 화면이 넓을수록 쓰기 좋습니다. 그래서 하단 탭 바를 상시 띄우지 않고 작은 원형 손잡이만 남겼습니다. 손잡이를 밀어 올리면 세 도구와 홈 버튼이 부채꼴로 펼쳐지고, 바깥을 누르면 접힙니다.

  • 엄지 하나로버튼이 화면 아래 가운데에 모여 한 손으로 쥔 채 닿습니다.
  • 다시 누르면 홈이미 열린 탭을 한 번 더 누르면 홈 화면으로 돌아갑니다.
  • 상태 유지탭을 오가도 각 화면은 지워지지 않아 입력한 금액, 검색 결과, 번역 결과가 그대로 남습니다.

06 계정과 설정

로그인은 필요한 곳에서만

환율과 번역은 로그인 없이 쓸 수 있습니다. 서버 비용이 드는 장소 검색만 로그인을 요구하고, 검색창에서 그 이유를 바로 알려 줍니다.

  • 로그인아이디·비밀번호와 Google 로그인을 지원합니다. 아이디 찾기와 비밀번호 재설정도 앱 안에서 처리합니다.
  • 토큰 관리토큰은 기기의 보안 저장소에 두고, 액세스 토큰이 만료되면 자동으로 다시 발급받습니다.
  • 세션 복구 실패네트워크 문제로 로그인 상태를 확인하지 못하면 상단에 배너를 띄우고 다시 시도할 수 있게 합니다.
  • 화면 설정자국 통화, 화면에 보일 통화, 자릿수, 라이트·다크 모드를 고릅니다.

07 구조

앱은 서버 하나만 알고 있습니다

환율, 코인 시세, 장소, 번역은 모두 외부 서비스지만 앱은 Tripbler 서버의 /api/v1만 호출합니다. 외부 API 키는 서버에만 있고, 호출 제한과 캐시도 서버에서 관리합니다.

  • 시세·차트 캐시, 보안 저장소 토큰

  • 외부 응답 캐시와 갱신 시각 관리

저장값 먼저, 그다음 갱신

시세와 차트는 저장해 둔 값을 바로 보여 주고 뒤에서 다시 조회합니다. 서버가 알려 준 갱신 시각과 오래된 값 여부를 화면까지 그대로 전달합니다.

늦게 온 응답은 버리기

통화나 기간을 빠르게 바꾸면 이전 요청의 응답이 나중에 도착할 수 있습니다. 화면이 사라졌거나 요청이 바뀐 뒤 온 응답은 반영하지 않습니다.

국가 통화와 코인 분리

두 데이터는 출처와 갱신 주기가 달라 로직을 나눴고, 화면에서는 같은 통화 줄과 차트를 함께 씁니다.
