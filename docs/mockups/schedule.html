일정 화면 목업

샘플 데이터와 화면 동작만으로 만든 목업입니다. 실제 저장·알림·지도 연동은 없고, 새로 고침하면 처음 상태로 돌아갑니다. 설계는 schedule.md에 있습니다.

  1. 빈 상태 — 가운데 +를 누릅니다.
  2. 입력 — 제목을 쓰고, 날짜·시간·장소(왼쪽 지도 아이콘)·알림·메모를 고른 뒤 저장합니다.
  3. 저장된 타임라인 — 오른쪽 점, 왼쪽 제목. 마지막 일정 아래 점선과 +가 이어집니다.
  4. 상세 조회 — 제목이나 점을 누릅니다.
  5. 다음 일정 추가 — "다음 일정을 추가해 보세요"나 +를 누르고 저장하면 점선이 실선으로 바뀌며 새 일정이 붙습니다.
  • 제목은 필수입니다. 비우고 저장하면 안내가 뜹니다.
  • 취소하면 일정이 만들어지지 않고 보던 화면이 그대로 남습니다.
  • 수정·삭제는 이번 범위 밖입니다.
