상태 흐름

실시간 모드가 오가는 상태

화면은 아래 상태 사이를 오갑니다. 로딩·빈 결과·실패를 구분하고, 갱신하지 못한 환율은 마지막 값과 시각을 유지한다는 앱의 원칙을 그대로 따릅니다.

배터리와 발열

카메라와 글자 인식을 계속 돌리면 배터리를 많이 씁니다. 움직임이 없으면 일정 시간 뒤 자동으로 멈추고, 화면이 꺼지거나 다른 탭으로 가면 카메라를 바로 끕니다. 멈추기까지의 시간을 정해야 합니다.

미리보기라는 표시

기기 번역은 서버 번역보다 품질이 낮고, 영어가 아닌 언어끼리는 영어를 거쳐 번역할 수 있습니다. "미리보기" 표시를 어디까지 드러낼지, 찍기 모드로 넘어가는 안내를 얼마나 자주 보여 줄지 정해야 합니다.

읽기 어려운 사람을 위해

사진 위 작은 글자는 큰 글자 설정이나 화면 낭독기와 잘 맞지 않습니다. 멈춘 화면에서 줄 목록으로 보기를 함께 둘지, 겹친 글자의 최소 크기를 얼마로 할지 정해야 합니다.

원문 언어 고정 풀기

자동 감지로 고정한 언어가 틀렸거나 다른 나라 글자를 비출 때, 언어 막대를 눌러 다시 감지하게 할지, 섞인 글자를 어떻게 다룰지 정해야 합니다.

모델 관리

여러 나라를 다니면 언어 모델이 쌓입니다. 설정에 받은 모델 목록과 지우기를 둘지, 처음 받을 때 Wi-Fi에서만 받게 할지 정해야 합니다.

사진은 남기지 않음

실시간 모드는 사진을 저장하지도 보내지도 않습니다. "이 화면 찍기"를 눌렀을 때만 찍기 모드로 넘어가 글자 조각을 서버에 보냅니다. 이 차이를 화면에서 어떻게 알릴지 정해야 합니다.
