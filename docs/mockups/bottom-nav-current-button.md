# 하단 메뉴 '현재 화면 버튼' 상태 디자인 변경 (설계안)

작성: 2026-11-26 · 상태: 구현됨(위젯 테스트로 확인, 실기기 미확인) · 바탕 문서: [bottom-nav.md](bottom-nav.md)

> **치수 변경(2026-11-27 사용자 요청)**: 바깥 원 64 → **74**, 안쪽 버튼 40 → **55**(2026-11-27에 50으로 했다가 다시 5 키움, 아이콘 그림 22는 버튼 정가운데에 고정). 따라서 아이콘 상태 중심 높이 44 → 49, 촬영 고리 48 → 63(버튼 + 8), 꼬리표 아래 끝 84 → 94(위 끝 118), 안내 문구 아래 여백 112 → 122. 아래 본문은 이 값으로 고쳤다. 코드 값은 `lib/widgets/navigation/bottom_menu_capture_marks.dart`의 `BottomMenuMetrics`에 모여 있다.

## 1. 바꾸는 것

[bottom-nav.md](bottom-nav.md) 2절의 **현재 화면 아이콘** 상태 하나만 바꾼다. 점 상태, 부채꼴 메뉴, 제스처 기준값, 화면 이동 규칙은 그대로 둔다.

| | 지금(구현됨) | 바꾼 뒤 |
| --- | --- | --- |
| 구성 | 반투명 원(64) 하나에 아이콘·이름·"눌러서 촬영"을 함께 넣음 | 반투명 원(74) 위에 **작은 불투명 원형 버튼(55)** 을 얹음 |
| 색 | 원과 글자 모두 primary 계열의 옅은 색 | 바깥 원은 옅게, 안쪽 버튼은 진한 primary로 채움 |
| 이름 | 원 안 아이콘 아래 | 원 안에서 뺌. 화면 낭독기 라벨로 알림(4절) |
| 촬영 안내 | 원 안 이름 아래 "눌러서 촬영" | 원 위에 작은 꼬리표(5절) |

**목적**: 손끝으로 누를 곳(안쪽 버튼)과 끌어 펼치는 판(바깥 원)이 눈으로 구분되게 한다. 카메라 미리보기처럼 복잡한 화면 위에서도 버튼이 묻히지 않게 한다.

## 2. 모양

```
            ┌───────────┐
            │ 눌러서 촬영 │   ← 꼬리표(번역 촬영 화면에서만)
            └───────────┘
               ╭─────╮
            ╭──┤ ●●● ├──╮     바깥 원: 지름 74, 반투명
            │  │  📷  │  │     안쪽 버튼: 지름 55, 불투명 primary
            ╰──┤     ├──╯     둘 사이 고리 폭 9.5
               ╰─────╯
  ─────────────── 화면 아래에서 12 ───────────────
```

| 요소 | 값 | 이유 |
| --- | --- | --- |
| 바깥 원 | 지름 74, 화면 아래에서 12 | 부채꼴로 변하는 배경의 시작 모양이다. 2026-11-27 사용자 요청으로 64에서 74로 키웠다(반원 300 × 150은 그대로) |
| 바깥 원 색 | `surface` 반투명(라이트 0.72, 다크 0.60) + `primary` 22% 테두리 1 | 지금의 `primary` 16%는 카메라 미리보기 위에서 거의 안 보인다. 밝은 면을 깔아 어떤 배경에서도 판이 보이게 한다 |
| 안쪽 버튼 | 지름 55, `primary` 불투명 채움, 바깥 원 정가운데 | 누를 곳을 한 점으로 모은다. 고리 폭 9.5가 남아 판과 버튼이 구분된다 |
| 안쪽 아이콘 | 22, `onPrimary`, 버튼 정가운데(누르는 중·끄는 중에도 고정) | 테마의 primary/onPrimary 대비(4.5:1 이상)를 그대로 쓴다. 2026-11-27에 크기 32·위로 5를 시도했다가 사용자 요청으로 둘 다 되돌렸다 |
| 그림자 | 안쪽 버튼에만 elevation 2 정도의 옅은 그림자 | 판 위에 떠 있는 버튼으로 보이게 한다. 바깥 원에는 넣지 않는다 |

### 안쪽 아이콘 (메인 판단)

| 화면 | 아이콘 |
| --- | --- |
| 환율·지도·AI 홈 | 그 화면의 탭 아이콘(지금과 같음) |
| 번역 촬영 화면(누르면 촬영) | 카메라 아이콘 `Icons.photo_camera` |
| 번역 결과 화면(누르면 아무 일 없음) | 번역 탭 아이콘 |

누르면 촬영되는 화면에서만 셔터 모양으로 바꾼다. 셔터를 없앤 화면이라 "이게 셔터"라는 신호가 아이콘에 있어야 한다. 여기가 어느 화면인지는 화면 자체(카메라 미리보기)가 이미 보여 준다.

## 3. 상태별 모습

| 상태 | 바깥 원 | 안쪽 버튼 | 꼬리표 |
| --- | --- | --- | --- |
| 기본 | 위 값 | primary + 아이콘 | 번역 촬영 화면만 "눌러서 촬영" |
| 누르는 중 | 그대로 | 0.92배로 줄었다가 놓으면 돌아옴, 그림자 없앰 | 그대로 |
| 촬영 중 | 그대로 | 아이콘을 지우고 안쪽 버튼 둘레(지름 63)에 도는 고리(굵기 2.5, `primary`, 바탕 고리 20%) | "찍는 중" |
| 촬영 중 + 애니메이션 줄이기 | 그대로 | 멈춘 카메라 아이콘, 고리 없음 | "찍는 중" |
| 카메라 준비 전(번역 촬영 화면) | 그대로 | `primary` 38% 투명도, 아이콘 `onPrimary` 그대로 | 숨김 |
| 끌기 시작(p > 0) | 반원으로 변하기 시작 | 6절 이어받기 | p 0.2까지 흐려져 사라짐 |

- 고리는 안쪽 버튼(55)과 바깥 원(74) 사이 고리 폭 9.5 안에 그린다. 버튼을 가리지 않고, 판 밖으로 나가지 않는다.
- 촬영 중에 4초 접기를 하지 않는 규칙은 그대로 둔다.

## 4. 이름과 접근성

- 원 안에서 이름 글자를 뺀다. 글자가 없으니 큰 글자 설정에서 줄여 맞출 일도 없어진다(bottom-nav.md 7절의 "배율 1.3까지"는 꼬리표에만 적용).
- 화면 낭독 라벨은 지금과 같다: "현재 화면: 번역", 힌트 "위로 끌어 메뉴 열기, 두 번 눌러 촬영". 촬영 중이면 "사진 찍는 중"을 붙인다. "메뉴 펼치기" 접근성 동작도 그대로 둔다.
- **터치 영역은 바깥 원 전체(74)** 다. 고리 부분을 눌러도 안쪽 버튼을 누른 것과 같다.
- 이름이 보이지 않아도 되는 이유: 아이콘 상태는 화면 아래 가운데에 잠깐(4초) 보이는 단계이고, 화면 이름은 위쪽 상단 바(`AppTopBar`)에 이미 있다. 부채꼴에서는 버튼마다 이름이 그대로 보인다.

## 5. 촬영 안내 꼬리표

- 번역 촬영 화면에서 아이콘 상태일 때만, 바깥 원 위 끝에서 8 위에 둔다.
- 모양: 높이 24, 좌우 여백 10, 완전히 둥근 모서리, `inverseSurface` 0.85 바탕, `onInverseSurface` 글자(`labelSmall`). 카메라 미리보기 위에서도 읽혀야 해서 반투명 판보다 진하게 한다.
- 글자: 평소 "눌러서 촬영", 촬영 중 "찍는 중". 카메라 준비 전에는 숨긴다.
- 아이콘 상태에서 처음 나타날 때만 보인다. 점으로 접히면 함께 사라진다.
- 꼬리표 위 끝은 화면 아래에서 약 118이라, 사진 화면과 기존 번역 화면은 안내 문구(개인정보 안내) 아래를 **122** 비운다(`BottomMenuMetrics.contentClearance`).

## 6. 모션

### 점 → 아이콘 (약 200ms, 감속 곡선)

1. 점(10)이 바깥 원(74)으로 커진다.
2. 원이 60%쯤 커졌을 때 안쪽 버튼이 0.6배 → 1배로 커지며 나타난다(투명도 0 → 1).
3. 꼬리표는 맨 마지막에 위로 4 떠오르며 나타난다.

접힐 때는 거꾸로: 꼬리표 → 안쪽 버튼 → 바깥 원 → 점.

### 아이콘 → 부채꼴 (끄는 진행률 p에 연동)

안쪽 버튼이 사라지지 않고 **부채꼴의 현재 화면 버튼이 된다.**

| p | 0 | 1 |
| --- | --- | --- |
| 안쪽 버튼 중심 | (0, 49), 바깥 원 가운데 | 현재 화면 버튼 자리(예: 번역 (+93, 72), AI 홈이면 (0, 42)) |
| 안쪽 버튼 지름 | 55 | 64(AI 홈이면 76) |
| 안쪽 아이콘 | 카메라 또는 탭 아이콘 | 탭 아이콘(이름도 아래에 나타남) |

- 위치와 크기는 p로, 이름과 아이콘 바꾸기는 p 0.4~0.8 사이에 겹쳐 바꾼다.
- 부채꼴에서 현재 화면 버튼은 따로 그리지 않고 이 버튼이 맡는다. 두 개가 겹쳐 보이지 않게 한다.
- 다른 버튼은 지금처럼 가운데에서 퍼진다.
- 이유: 지금은 아이콘이 흐려지고 부채꼴의 강조 버튼이 새로 나타난다. 한 버튼이 자리를 옮기면 "내가 누르던 것이 저기로 갔다"가 이어져 보인다.
- 애니메이션 줄이기: 크기·위치 보간은 손가락을 따라가므로 유지하고(bottom-nav.md 5절 원칙), 아이콘 바꾸기는 짧은 투명도 변화로만 한다.

## 7. 바뀌지 않는 것

- 점 상태와 그 터치 영역(48)
- 끌기 기준: 8px, 120px, 0.35, 0.5px/ms
- 부채꼴 반원(300 × 150)과 다른 버튼 자리·모양
- 탭 선택, 재선택, AI 홈, 4초 접기, 바깥 누르기
- 촬영 연결(`NavigationCaptureController`, `busy`)

## 8. 결정 (2026-11-26 사용자 승인)

1. **이름 글자를 원에서 뺀다**(4절). 바깥 원은 64로 유지한다.
2. **번역 촬영 화면에서 안쪽 아이콘을 카메라로 바꾼다**(2절).
3. **바깥 원 색을 `surface` 반투명 + `primary` 22% 테두리로 바꾼다.** 부채꼴 배경도 같은 색으로 시작하므로 반원 색도 함께 바뀐다.
