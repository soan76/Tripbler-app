# 면세 화면 (설계 · 목업)

작성: 2026-11-28 · 상태: 설계와 HTML 목업, 앱에는 아직 구현하지 않음 · 목업: [duty-free.html](duty-free.html) · 하단 메뉴 자리: [bottom-nav.md](bottom-nav.md) 10-6절

> 화면의 면세 기준·환율·세율은 모두 **예시**다. 실제 기준은 나라마다 다르고 바뀐다. 구현할 때 관세청 공식 기준을 확인하고, 규칙은 서버에서 받는다.

## 1. 범위

- 포함: 한국 입국 기준 표시, 나이(만 19세 이상 여부), 일반 물품 한도 요약, 별도 기준(주류·담배·향수) 요약, 기준 정보, 신고 안내와 예상 세금(예시), 산 물건 목록(추가·수정·삭제·새 여행 시작), 영수증 찍기와 검토.
- 제외: 다른 나라 입국 기준(입국 국가 선택은 나중), 은행·카드·마이데이터 연결(사용자 결정), 현지 택스리펀드, 알림(한도 90%·귀국 전날), AI 질문 연동.

## 2. 화면 (위에서 아래)

1. **기준 줄**: "한국 입국 기준 · 만 19세 이상" + `변경`(나이만 고름, 생년월일은 받지 않음).
2. **일반 물품 한도**: "남은 한도 $425" 또는 "한도 초과 $52"(음수 대신, 오류색). 아래 현지 통화 환산 또는 "초과한 금액에 세금이 붙을 수 있어요". 진행 막대(90% 이상 경고색, 초과 오류색)와 "지금까지 $375 / 한도 $800".
3. **별도 기준**: 일반 한도와 따로 계산한다고 밝히고 주류(병 수·용량·금액), 담배(갑), 향수(mL)를 줄마다 `없음 / 이내 / 초과`로 보인다. 만 19세 미만이면 주류·담배는 "면세 안 됨".
4. **기준 정보 한 줄**: 기준일, "환율은 참고용(세관 환율과 다를 수 있음)", 확인 시각, `관세청` 링크.
5. **신고 안내**(초과일 때만): "입국할 때 세관 신고가 필요할 수 있어요"와 무엇이 초과인지. 단정하지 않고 "정확한 판단은 세관에서 해요". `예상 세금 보기(예시)`를 펼치면 계산 근거(초과 금액 → 원화, 예시 세율, 자진신고 감면 예시, 합계)를 보인다. 별도 기준 초과분은 세율이 달라 계산하지 않는다고 적는다.
6. **산 물건 목록**: 상품명 + 분류, 구매처 · 날짜 · 수량/용량, 오른쪽에 현지 금액과 통화 코드(굵게), "≈ $달러". 영수증에서 읽은 불확실한 줄은 "확인 필요". 위에 `새 여행 시작`(확인창 뒤 모두 비움).
7. **하단**: `직접 입력 | 영수증 찍기`.

## 3. 입력·수정 카드

- 일정 입력 카드와 같은 모양(아래에서 올라옴, 구분선). 추가는 `취소 | 저장`, 수정은 왼쪽 위 뒤로 가기와 `삭제 | 수정`.
- 칸: 분류(일반·주류·담배·향수), 상품명(필수), 수량(분류에 따라 "병 수·갑 수·개수"), 용량(주류 병당 L, 향수 개당 mL), 금액(합계)과 통화(JPY·USD·EUR·KRW), 달러 환산 즉시 표시, 구매처(현지 상점·출국 면세점·기내 면세).
- 삭제 확인창: 어느 금액이 어떤 계산(일반 한도·주류 기준 등)에서 빠지는지와 되돌릴 수 없음을 알린다.

## 4. 영수증 찍기와 검토

- 카메라 화면: "영수증 전체가 보이게 찍어 주세요 · 사진은 서버로 보내지 않아요". 글자는 기기에서 읽는다.
- 검토 화면: 가게·날짜·합계·읽은 줄 수. 넣는 방식은 **하나만** 고른다 — `항목별로 넣기`(고른 줄만, 합계는 넣지 않음) 또는 `합계 한 줄로 넣기`(일반 물품 한 줄, 주류·향수가 섞이면 별도 기준이 빠진다고 안내). 이렇게 합계와 항목이 이중으로 더해지지 않게 한다.
- 줄마다 선택 칸·분류·금액(고칠 수 있음). 불확실한 줄은 "확인 필요"로 표시하고 처음엔 고르지 않는다(금액을 확인한 뒤 고름).
- 중복: 가게·날짜·합계가 같은 영수증을 이미 넣었으면 "이미 추가한 영수증일 수 있어요"를 보이고 버튼을 `그래도 추가`로 바꾼다.
- 하단 `다시 찍기 | 목록에 추가 (N)`(고른 게 없으면 비활성).

## 5. 상태 (목업 샘플)

구매 없음 · 한도 이내 · 한도 근접(90% 이상) · 한도 초과 · 별도 제한 초과 · 환율 오래됨(저장된 환율과 시각 안내) · 계산 불가(기준·환율도 저장된 것도 없음, 요약 대신 "다시 시도", 목록은 현지 금액만).

## 6. 기능 구조 (구현 때, Riverpod)

| 계층 | 할 일 |
| --- | --- |
| 서버 | 면세 규칙 API(예: `GET /api/v1/duty-free/rules`): 한도·별도 기준·세율·기준일. 관세청 공식 API는 확인하지 못해 서버 데이터로 관리 |
| Service | 규칙 받기·캐시(마지막 성공값과 시각 유지), 산 물건 기기 저장, 영수증 글자 읽기(기존 ML Kit·가격 뽑기 재사용) |
| Notifier | 산 물건 목록, 나이, 계산 결과(일반 합계·별도 기준·초과 여부), 영수증 검토 상태와 추가한 영수증 키 |
| 화면 | 면세 화면, 입력 카드, 영수증 촬영·검토 |

- 환율은 기존 환율 Notifier·캐시를 쓴다. 오래된 값이면 그 시각을 보인다.
- 상품명·금액은 로그에 남기지 않는다. 영수증 사진은 서버로 보내지 않는다.

## 7. 정할 것

- 실제 기준 값(일반 한도, 주류·담배·향수 기준, 국내 면세점 구매 포함 여부, 세관 환율)은 관세청 공식 자료로 확인.
- 예상 세금을 보여 줄지, 보여 준다면 품목별 세율 데이터를 어디서 받을지.
- 동행이 있을 때 사람별로 나눠 볼지.
- 영수증 항목 합계와 영수증 합계가 다를 때 안내할지.
- 영수증으로 넣은 물건을 지우면 같은 영수증을 다시 넣을 수 있게 할지(목업은 추가한 영수증을 계속 기억함).
