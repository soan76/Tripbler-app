일정 보관함·백업 목업

샘플 데이터로만 움직입니다. 보관·복원·삭제는 이 페이지 안에서만 바뀌고 실제로 저장하지 않습니다. 일정 추가·수정은 schedule.html에 있습니다.



  • 보관함(다음 단계): 일정을 누르면 앱과 같이 수정 화면이 열리고, 그 안의 "보관함으로 이동"으로 옮깁니다. 위 오른쪽 상자 아이콘으로 열고, 항목을 눌러 다시 꺼내거나 삭제합니다. 자동으로 지우지 않습니다.
  • 백업: 위 오른쪽 시계 아이콘. 기기와 서버(다음 단계)를 나눠 보고, "지금 백업"으로 현재 일정의 복사본을 만듭니다. 직접 백업은 위치마다 최근 3개만 남고, 읽지 못해 보관한 백업은 개수에 세지 않으며 직접 지우기 전에는 지우지 않습니다.
  • 지금 일정이 마지막 직접 백업과 같으면 "지금 백업"이 꺼집니다.
  • 읽지 못한 일정이 있으면 일정 화면 위 알림의 확인으로 기기 백업 목록에 갑니다. 확인하거나 닫은 백업은 기억해서 앱을 다시 켜도 다시 띄우지 않습니다(아래 "앱 다시 켜기"로 확인).
  • 일정을 불러오지 못한 상태(시나리오 "불러오기 실패")에서는 백업 만들기와 되살리기를 막습니다. 기존 저장값을 덮어쓰지 않기 위해서입니다.
  • 서버 백업은 로그인해야 쓸 수 있고, 처음 백업할 때 일정 제목·장소·메모가 서버로 간다는 동의를 받습니다.
  • 복원할 때 지금 목록이나 보관함에 이미 있는 일정은 처음에 고르지 않고, 복원한 뒤에도 백업은 남습니다.
  • 삭제는 무엇이 지워지고 지금 일정에 어떤 영향이 있는지 확인창으로 알립니다.
