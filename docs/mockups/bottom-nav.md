# 하단 이동 메뉴 3단계 목업 (구상안)

작성: 2026-11-26 · 상태: 구상안, 아직 구현하지 않음 · 함께 보는 파일: [bottom-nav.html](bottom-nav.html) (눌러 보고 끌어 볼 수 있는 프로토타입)

## 1. 목적

지금 하단 메뉴는 작은 고리를 끌면 부채꼴 버튼(환율·지도·번역·AI)이 한 번에 펼쳐진다. 이를 **작은 점 → 현재 화면 아이콘 → 부채꼴 메뉴**의 3단계로 바꾸고, 끄는 만큼 원형 배경이 반원으로 이어서 변하게 한다. 화면을 덜 가리면서, 지금 어느 화면인지와 메뉴가 어디서 나오는지를 손끝에서 알 수 있게 하는 것이 목표다.

- 참고 이미지(2026-11-26 받음)는 반원 배경과 버튼 배치·모양의 참고로만 쓴다. 버튼 크기(64·76)는 지금 `lib/widgets/bottom_tab_bar.dart`와 같고, 버튼 자리는 이미지에 맞춰 조금 올렸다(5절).
- 이미지의 화면 구성(가운데 "오늘" 등)은 가져오지 않는다. 메뉴의 버튼은 지금처럼 환율·지도·번역·AI다.

### 참고 이미지에서 가져온 모양

| 요소 | 모양 |
| --- | --- |
| 반원 배경 | 옅은 청회색 반투명 면, 가는 점선 테두리, 아래는 화면 아래에 붙어 평평 |
| 일반 버튼(환율·지도·번역, 64) | 반투명 회색 원 + 옅은 회색 테두리, 진회색 아이콘. 이름은 원 아래 가장자리에 걸친 흰 꼬리표(지금 앱의 테두리 틈 모양과 같음) |
| 가운데 버튼(AI, 76) | 같은 원 모양, 이름을 원 안 아이콘 아래에 씀 |
| 현재 화면 | 파란 원(지금 앱의 선택색 `Colors.blue`) + 흰 아이콘, 이름 굵게. 가운데 버튼이 현재 화면이면 이름도 흰색 |

## 2. 상태

| 상태 | 보이는 것 | 누르기 | 끌기 |
| --- | --- | --- | --- |
| **점** (기본) | 하단 가운데 반투명 작은 점(지름 10). 터치 영역은 48×48 | 현재 화면 아이콘 상태로 커짐. **어느 화면에서도 촬영하지 않음** | 없음(먼저 눌러 키운다) |
| **현재 화면 아이콘** | 반투명 원형 배경(지름 64) 위에 현재 화면 아이콘과 이름(환율·지도·번역·AI) | 번역 촬영 화면에서만 **사진 촬영**. 그 밖의 화면에서는 아무 일 없음 | 위로 끌면 부채꼴로 펼쳐짐(진행률에 연동) |
| **부채꼴 메뉴** | 바닥이 평평하고 위가 둥근 반원 배경 + 환율·지도·번역·AI 버튼. 현재 화면 버튼 강조 | 다른 화면 버튼: 이동하며 점으로 접힘 · 현재 화면 버튼: 이동 없이 점으로 · 메뉴 바깥: 이동 없이 점으로 | 아래로 끌면 진행률이 줄며 원형으로 돌아옴 |

- 현재 화면 아이콘 상태에서 일정 시간(초안 4초) 아무 입력이 없거나 메뉴 바깥을 누르면 점으로 돌아간다.
- AI 홈으로는 부채꼴의 AI 버튼으로만 간다. 다른 탭을 다시 누르는 것으로 홈에 가던 지금 규칙("선택된 탭을 다시 누르면 홈")은 **없앤다**. 현재 화면 재선택은 접기만 한다.

## 3. 상태 전환

```
점 ──누르기──▶ 현재 화면 아이콘 ──위로 끌기(진행률 p)──▶ 부채꼴
 ▲                 │  ▲                                  │
 │   바깥 누르기·   │  └──놓기(p < 기준) / 아래로 끌기 ────┘
 │   4초 무입력     │
 └─────────────────┘
 ▲                                                        │
 └── 버튼 선택(이동) · 현재 화면 재선택 · 바깥 누르기 ────────┘  (부채꼴 → 원형 → 점 순서로 접힘)
```

## 4. 제스처 규칙

| 항목 | 초안 값 | 이유 |
| --- | --- | --- |
| 누르기와 끌기 구분 | 손가락이 **8px** 넘게 움직이면 끌기. 끌기로 판정되면 그 손가락을 떼도 누르기(촬영)로 처리하지 않음 | 끌다가 놓을 때 촬영되는 오작동 방지 |
| 완전히 펼치는 거리 | 위로 **120px** = 진행률 1 | 엄지 한 번으로 닿는 거리 |
| 놓을 때 펼침 기준 | 진행률 **0.35 이상**, 또는 위쪽 속도 **0.5px/ms 이상**이면 펼침. 아니면 원형으로 복귀 | 짧게 휙 올려도 펼쳐지게 |
| 반대 방향 | 펼치는 중·접는 중에도 다시 잡으면 그 자리의 진행률에서 이어서 끈다 | 위치가 튀지 않게 |
| 메뉴 끌기 시작 위치 | 점·원형·반원 배경 안에서 시작한 손가락만 메뉴 끌기로 받는다 | 사진 확대·이동, 지도 이동과 충돌 방지 |

## 5. 모션 (드래그 연동 형태 전환)

하나의 배경이 원에서 반원으로 이어서 변한다. 원과 반원을 바꿔 끼우거나 겹쳐서 흐리게 바꾸지 않는다.

| 진행률 p | 0 (원형) | 1 (반원) |
| --- | --- | --- |
| 배경 너비 × 높이 | 64 × 64 | 300 × 150 |
| 위쪽 모서리 둥글기 | 32 (높이의 절반) | 150 (높이 전체) |
| 아래쪽 모서리 둥글기 | 32 | 0 (평평) |
| 배경 아래 끝 위치 | 화면 아래에서 12 | 0 (화면 아래에 붙음) |
| 기준점 | 하단 가운데 | 하단 가운데 |

- 너비·높이·둥글기·아래 끝 위치를 모두 같은 p로 보간한다. 하단 가운데를 기준으로 좌우와 위로 넓어지며, 아래는 평평해지고 위는 둥글어진다.
- 버튼은 p에 따라 가운데(현재 화면 아이콘 자리)에서 각자 자리로 퍼진다. 위치는 p, 투명도는 p를 조금 늦춘 값, 크기는 0.6 → 1.
- 버튼 자리(하단 가운데 기준, 버튼 중심): 환율(−93, 72) · 지도(0, 122) · 번역(+93, 72) · AI(0, 42). AI만 76, 나머지는 64. 참고 이미지의 자리다(AI는 지도 이름표와 겹치지 않게 4 내림). 지금 앱(환율·번역 52, 지도 102)보다 위로 올려, 지도 이름표가 가운데 AI 버튼에 가리지 않게 했다.
- 현재 화면 아이콘과 이름은 p가 커질수록 흐려지고, 그 역할을 부채꼴 안의 강조된 현재 화면 버튼이 이어받는다.
- 놓은 뒤 자리 잡기: 약한 스프링(감쇠비 0.9 안팎, 넘침 거의 없음), 놓을 때의 속도를 이어받는다.
- 점 ↔ 원형: 지름 10 ↔ 64를 약 200ms 감속 곡선으로.
- 접기 순서: 버튼이 가운데로 모임 → 배경이 원형으로 줄어듦 → 원형이 점으로 줄어듦. 이동할 때도 같은 순서로 접으며 화면이 바뀐다.
- 애니메이션 줄이기(기기 설정 `MediaQuery.disableAnimations`, 웹 프로토타입은 `prefers-reduced-motion`)가 켜져 있으면 형태 전환과 스프링을 끄고, 상태를 바로 바꾸며 짧은 투명도 변화만 쓴다. 끄는 동안의 진행률 연동은 유지한다(손을 따라오는 것은 움직임 연출이 아니라 조작 반응이므로).

## 6. 번역 촬영 화면

- 지금 카메라 카드의 별도 셔터(72)를 **없앤다**. 촬영은 현재 화면 아이콘(번역)을 누르는 것으로 한다.
- 갤러리와 플래시는 남긴다. 하단 가운데 메뉴와 겹치지 않게 좌우 끝에 둔다.
- 점 상태에서 누르면 촬영하지 않고 아이콘 상태로만 커진다. 촬영 화면에서 아이콘 상태일 때 이름 아래에 "눌러서 촬영"을 작게 함께 보여 준다.
- 부채꼴이 펼쳐지는 동안 갤러리·플래시·안내 문구는 흐려지고 눌리지 않는다. 다시 접히면 돌아온다.
- 찍은 사진을 확대·이동하는 결과 화면에서는 메뉴 배경 안에서 시작한 손가락만 메뉴로 받고, 그 밖의 두 손가락 확대·끌기는 사진이 받는다.

## 7. 접근성과 화면 크기

- 점·아이콘·버튼 모두 터치 영역 48×48 이상. 점은 화면 낭독기에 "메뉴 열기", 아이콘은 "현재 화면: 번역. 위로 끌어 메뉴 열기, 두 번 눌러 촬영"처럼 읽힌다.
- 화면 낭독기·스위치 사용자는 끌기가 어렵다. 아이콘 상태에서 "메뉴 펼치기" 접근성 동작을 제공해 끌기 없이 펼칠 수 있게 한다.
- 큰 글자: 이름 글자는 배율 1.3까지만 커지고 원형 배경 폭을 넘으면 줄여 맞춘다.
- 작은 화면(폭 320): 반원 폭 300이 화면 안에 들어가고 좌우 버튼이 잘리지 않는지 확인한다. 모자라면 반원과 버튼 간격을 폭에 맞춰 줄인다.

## 8. 완료 조건

- [ ] 점을 누르면 아이콘 상태가 되고, 어느 화면에서도 촬영하지 않는다.
- [ ] 아이콘을 위로 끄는 만큼 배경이 원에서 반원으로 이어서 변하고, 버튼이 가운데에서 자리로 퍼진다.
- [ ] 0.35 이상 또는 빠르게 올리고 놓으면 펼쳐지고, 아니면 원형으로 돌아온다. 튕김이 거의 없다.
- [ ] 애니메이션 도중 다시 잡아 반대로 끌어도 위치가 튀지 않는다.
- [ ] 다른 화면 버튼은 이동하며 점으로 접히고, 현재 화면 재선택·바깥 누르기는 이동 없이 접힌다. AI 홈은 AI 버튼으로만 간다.
- [ ] 번역 촬영 화면에서만 아이콘 누르기가 촬영이고, 끌기는 촬영하지 않는다. 별도 셔터는 없고 갤러리·플래시는 남는다.
- [ ] 메뉴가 셔터·갤러리·플래시·안내 문구와 겹치지 않는다. 사진 확대·이동과 충돌하지 않는다.
- [ ] 폭 320, 글자 배율 1.3·2.0에서 넘치거나 잘리지 않는다. 애니메이션 줄이기 설정을 따른다.

## 9. 구현 메모 (Flutter, 참고)

- 지금 `BottomTabBar`는 펼침 여부(bool)를 끌기 거리 24로 토글하고 `AnimatedPositioned`로 버튼을 옮긴다. 바꾼 뒤에는 상태(점/아이콘/부채꼴)와 진행률 p(0~1, `AnimationController.value`)를 두고, 끄는 동안 p를 손가락에 맞춰 직접 바꾸고, 놓으면 `SpringSimulation`으로 0 또는 1에 자리 잡게 한다.
- 배경은 p로 크기와 모서리 둥글기를 보간한 `RoundedRectangleBorder`(또는 `ShapeBorder.lerp`/`CustomPainter`)로 그린다. 버튼 위치는 `Offset.lerp(가운데, 자리, p)`.
- 화면 선택·AI 홈 이동은 지금처럼 `TabNotifier`가 맡는다. 다시 누르면 홈으로 가던 동작만 바뀐다.
- 촬영은 번역 화면이 아이콘 누르기를 받아 지금의 촬영 처리를 부르게 한다(메뉴 위젯이 카메라를 알지 않도록 콜백으로 연결).
- 파일이 450줄을 넘지 않게 상태·형태 계산(보간)·버튼 배치를 나누어 둔다.
